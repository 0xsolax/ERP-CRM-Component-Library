# 生产单管理组件规范

## 业务目标

把销售订单确认后的生产履约收口到唯一生产总单，支持按产品行推进采购释放、安排生产、交货和生产单导出。

## 关键规则

- 来源订单确认后创建或复用唯一生产总单。
- 手工生产单使用 `order_type=standalone`，不绑定来源订单。
- 采购入库只刷新既有生产总单，不自动代建生产总单。
- 产品行交货录入本次数量，后端累加累计已交货。
- 生产总单导出按产品行生成工作表，保留客户样板版式。

## 依赖

- 订单管理提供来源订单和产品快照。
- 产品物料提供产品图片、材料和规格快照。
- 采购供应商提供采购生成和入库反哺。
- 公共单据动作提供日志、锁定、解锁和重新确认。
