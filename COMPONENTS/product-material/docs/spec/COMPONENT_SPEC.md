# COMPONENT_SPEC｜product-material

## 目标

为 ERP/CRM 项目提供产品资料和物料主档能力，使报价、订单、采购、仓储和成本核算可以引用统一的产品、材料、伞架、面料、包材和工序数据。

## 推荐架构

```text
base-data 字段分类
  -> 物料主档：伞架 / 面料 / 材料 / 包材 / 工序
  -> 产品主档 product
  -> 产品 BOM：product_umbrella_frame / product_material / product_fabric / product_printing / product_packaging / product_process_price
  -> file-oss 图片记录
  -> quote / order / purchase 后续组件引用
```

## 后端规范

- 产品保存必须在一个事务内保存主档和所有 BOM 子项。
- 产品类型、面料、包材、伞架规格等基础数据应保存 ID 和名称快照。
- 产品图片不直接存 URL 到产品表，优先通过 `system_file` 关联。
- 删除使用逻辑删除，历史报价、订单引用不得被物理删除破坏。
- `ProductServiceImpl` 中产品筛选会根据基础数据名称反查产品关系表，新项目如改字段结构需同步改筛选逻辑。
- 产品主档 `totalCost`、`sellingPrice` 是参考值，不能替代报价单的报价时点快照。

## 前端规范

- 产品表单应一次维护产品基础信息、伞架、材料、面料、印刷、包材和工序。
- 材料、面料、包材、伞架、工序页面应作为产品录入前置维护入口。
- 下拉字段来自 `base-data`，不要在页面中写死业务选项。
- 图片上传复用 `file-oss` 上传组件和文件记录。
- 路由权限应使用产品、材料、工序权限码，不使用系统角色占位权限。

## 成本边界

| 成本项 | 产品主档建议 | 报价组件建议 |
| :--- | :--- | :--- |
| 伞架、面料、材料、包材、工序单价 | 可保存参考成本和组成明细 | 报价时复制为快照 |
| 损耗/杂费 | 可保存参考值 | 可按客户、数量、时点调整 |
| 包材计算 | 可保存默认包材和单价 | 允许手工调整或按公式重算 |
| 汇率、税费、物流、利润 | 不应放在产品主档 | 由报价或订单成本组件保存 |
| 客户敏感报价 | 不应放在产品主档 | 由报价组件按权限隔离 |

## 已知缺口

- 来源接口 `/fabric/deteil` 拼写错误，快照保留事实。
- 来源前端存在 `/packaging/typeList` 和 `/box-price/list`，当前后端未找到对应 controller。
- 快照未包含 `base-data` 和 `file-oss` 代码，需要与对应组件一同接入。
- 当前快照未做浏览器或接口联调验证。
