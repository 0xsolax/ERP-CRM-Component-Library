## 整理结论

- 产品资料不是单一产品表，必须包含规格、图片和 BOM。
- 工艺工价会影响成本，但报价时仍需要人工判断和历史成本参考。
- 包材成本在来源资料中存在强业务争议：可以维护固定包材，也可能按纸箱尺寸、层数、数量估算。
- 供应商报价不应直接绑死在报价单产品选择中；材料和供应商的关系更适合后续采购供应商组件处理。
- 产品主档应能服务报价、订单、采购和成本核算，但报价单必须保存时点快照，避免产品主档变更污染历史报价。
