# 公共单据动作组件规范

## 业务目标

把业务单据的正式动作、锁定、解锁、重新确认、负责人改派和审计查询沉淀为可复用公共层。

## 关键规则

- 正式状态动作必须由后端接口落库。
- 已确认、已转单、已取消等正式态单据进入锁定。
- 管理员解锁必须填写原因。
- 解锁修改后必须重新确认。
- 日志是审计记录，不允许当普通备注编辑。

## 接入单据

当前来源已接入：

- 报价：`documentType=quote`
- 订单：`documentType=order`
- 采购：`documentType=purchase`
- 生产：`documentType=production`
